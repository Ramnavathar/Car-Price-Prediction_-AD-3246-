# 🚗 Car Price Prediction Using Linear Regression

## 📌 Project Overview
Car Price Prediction is a Machine Learning project that predicts the resale price of a used car based on its features.

This project uses **Linear Regression**, a supervised machine learning algorithm, to estimate the selling price of a car.

The model takes car details as input and predicts the estimated resale price in Indian Rupees.

## 🎯 Project Objective
- Predict the resale price of a used car.
- Understand how car age and kilometers driven affect price.
- Apply Linear Regression to a real-world problem.
- Create an easy-to-use prediction interface.

## 📊 Dataset
The project uses the CarDekho dataset.

The dataset contains information about used cars, including:

- Year
- Selling Price
- Present Price
- Kilometers Driven
- Fuel Type
- Seller Type
- Transmission
- Owner Count

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- IPyWidgets

## ⚙️ Machine Learning Algorithm
**Linear Regression**

Linear Regression learns the relationship between car features and selling price. It uses this relationship to predict the price of a car with new input details.

## 🔄 Project Workflow
1. Load the dataset
2. Explore and understand the data
3. Clean the dataset
4. Perform data visualization
5. Select input features and target variable
6. Convert categorical data using One-Hot Encoding
7. Split data into training and testing sets
8. Train the Linear Regression model
9. Evaluate model performance
10. Predict the price of a new car

## 🧑‍💻 User Input
The user can select or enter:

| Car Details | Input |
|---|---|
| Car Age | Years |
| Kilometers Driven | Kilometers |
| Showroom Price | Lakhs |
| Fuel Type | Petrol / Diesel / CNG |
| Transmission | Manual / Automatic |
| Owner Count | Previous owners |
| Seller Type | Dealer / Individual |

## 📈 Model Evaluation
The model is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 💡 Output
The application displays the estimated resale price of the car in Indian Rupees based on the details entered by the user.

## 🚀 How to Run
1. Open Google Colab.
2. Create a new notebook.
3. Copy the project code into separate cells.
4. Run all cells in order.
5. Enter the car details in the prediction interface.
6. Click **Predict Car Price** to view the estimated price.

## ⚠️ Disclaimer
The predicted price is an estimate based on the dataset used for training. Actual resale prices may vary depending on car condition, location, market demand, and other factors.
